# IONIC

Es un kit de herramientas de interfaz de usuario (UI) de código abierto para crear aplicaciones multiplataforma (móviles, web y de escritorio) a partir de un único código base.

## Installation

Para descargar las dependencias del proyecto ejecute:

```bash
npm install
```

## Usage


para iniciar la aplicación ejecute en consola desde la ruta del proyecto
```bash
npm install
```
